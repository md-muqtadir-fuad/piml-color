# Physics-informed hybrid inverse recipe reconstruction

Code for the manuscript *A Physics-Informed Hybrid Inverse Machine Learning Framework for High-Dimensional Sparse
Recipe Reconstruction* (Fuad, Adnan, Rahman, Al Aziz; Bangladesh University of Engineering and Technology).

The framework reconstructs a sparse dye recipe (which dyes, and how much of each) from a target reflectance
spectrum. It has four modules:

| Module | What it does | Code |
|---|---|---|
| Spectral Calibration Module | Calibrates Kubelka–Munk unit *K/S* spectra from multi-dye production records (Langmuir-type uptake, weighted NNLS, hue-family shrinkage) | `src/piml_color_recipe/inverse/km_physics.py`, `fit_km`, `make_km` |
| Dye-Set Selector | Builds candidate dye sets from the recipe history, fits each by bounded KM, and ranks them with a conditional-logit choice model averaged over L2 penalties | `scripts/60_physics_inverse_experiments.py` (`fold_bundle`, `fold_choice_probs`) |
| Amount Estimator | Equal blend of KM amounts and Extra Trees amounts on the selected set | `chosen_vectors` in script 60 |
| Uncertainty Quantifier | Cross-validation-calibrated intervals for the amounts, one quantile per hue family | `scripts/64_uncertainty_check.py` |

## Data

The industrial records used in the paper cannot be shared under a non-disclosure agreement. **This repository
contains no industrial data.** The folder `data/` holds a **synthetic dataset** with the same structure, generated by
`scripts/00_make_synthetic_data.py` from invented dyes (smooth Gaussian absorption bands), invented shades and
invented recipes. It lets the whole pipeline run end to end; results on it do **not** reproduce the numbers in the
paper.

| File | Content |
|---|---|
| `data/processed/features_supervised.csv` | One row per lab dip: 36 dye amounts (`vec__dye_*_pct`, % on weight of fiber), target reflectance and *K/S* at 400–750 nm, spectral descriptors, substrate variables, process auxiliaries, lab-dip color differences |
| `data/global_naming/global_dye_mapping_active_36.csv` | Dye column → hue family |
| `data/interim/recipe_dye_long.csv` | Dye at each recipe position (long format) |
| `data/splits/groupkfold_target_id.json` | Strict CV: five folds grouped by target shade |
| `data/splits/groupkfold_recipe_no.json` | Recipe-grouped CV: five folds grouped by recipe |

To regenerate it: `python scripts/00_make_synthetic_data.py --seed 2026`.

## Installation

Python 3.11.

```
pip install -r requirements.txt
pip install -r requirements-optional.txt   # only for scripts 61 and 62
```

## Running

All scripts write to `outputs/`.

```
python scripts/60_physics_inverse_experiments.py --exp e00b   # baselines: ML reference, retrieval, oracle
python scripts/60_physics_inverse_experiments.py --exp e01    # Kubelka-Munk forward fit
python scripts/60_physics_inverse_experiments.py --exp e02    # exhaustive KM matching (color matching alone)
python scripts/60_physics_inverse_experiments.py --exp e16    # final method and its no-physics ablation
python scripts/64_uncertainty_check.py                        # amount intervals and their coverage
python scripts/69_review_checks.py                            # calibration, identifiability and strata checks
python scripts/70_review_experiments.py --only B S R          # blend control, KM simulation, repeated CV
```

The other experiments of script 60 (`e03`–`e15`, `t01`, `t02`) and scripts 61 (`--exp A01 ...`) and 62 are the
development and comparison methods reported as having no significant gain. Scripts 63, 65 and 68 draw the figures
and tables and expect the experiments above, and those of scripts 61 and 62, to have been run.

Main settings: strict cross-validation grouped by target shade (unseen shades) and by recipe; paired cluster
sign-flip tests (20,000 flips) with Holm correction; activity threshold 0.01 % OWF; KM uptake constant and
hue-family shrinkage selected by inner cross-validation; blend weight 0.5.
